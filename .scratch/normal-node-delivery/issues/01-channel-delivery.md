# 01: 按渠道下发“普通”专属节点

**What to build:** 节点管理员可以使用现有标签选择节点的订阅渠道：仅有“普通”渠道标签时为普通专属，仅有“客户端”渠道标签时为客户端专属，同时有两个标签或两个都没有时共享。普通订阅与客户端订阅分别获得对应节点；旧 App 配置沿用普通订阅渠道，网页列表继续展示全部有权限的节点。通过实际 HTTP 请求和返回配置验证完整行为。

- [x] 隐藏节点、权限组不匹配及账户不可用时的行为保持原契约，渠道标签不能扩大用户的节点权限。
